# Project Skills

## Impeccable

Impeccable is the required design workflow for Studio Lemus visual work. It provides product/design context, UI planning and review commands, and a deterministic anti-pattern detector.

- Native OpenCode installation: `.opencode/skills/impeccable/`
- Project reference: `skills/impeccable/` (a junction to the native installation, not a second copy)
- Load before changing Vue, CSS, layouts, visual components, screens, or animation.
- Read `PRODUCT.md` for product truth and `DESIGN.md` for the visual system before visual changes.
- Run the detector before delivering visual changes. OpenCode has no provider-native Impeccable hook, so this project enforces the final detector run through `AGENTS.md`.

Visual authority is governed by `PRODUCT.md`, `DESIGN.md`, `.impeccable/design.json`, and `docs/STUDIO_LEMUS_VISUAL_SYSTEM.md`.
