# Studio Lemus Agent Instructions

## Visual Work

Before modifying any Vue, CSS, visual layout, component, animation, or screen:

1. Read `DESIGN.md`.
2. Read `skills/impeccable/SKILL.md`.
3. Select and follow the relevant `/impeccable` command reference.
4. Review responsive behavior, accessibility, and visual anti-patterns.
5. Run the Impeccable detector on the changed visual targets before delivery.

This rule applies only to visual work. Backend-only changes do not require Impeccable.
